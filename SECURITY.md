# Security

Crest is unreviewed. It runs on local chains and test networks only, with test tokens. Do not put real money in it.

## Reporting a problem

Report a security problem through GitHub's private advisory form for this repository: the **Security** tab, then **Report a vulnerability**. Please do not open a public issue for it.

Say what you found, how to reproduce it (a failing forge test is ideal), and what it lets someone do.
